In this project, I was told to make the hardware and PCB for a midi keypad or something similar. I chose to focus more on the capacitive touch buttons. I used kicad to create the PCB design and to plan how the project will look once build.

A schematic diagram is a diagram showing how all the components are connected. Using kicad, you assign footprints/real components to every symbol and device. This allows kicad to translate the schematic diagram into a PCB. 

Using kicad, I created a PCB -->

<img width="726" height="421" alt="image" src="https://github.com/user-attachments/assets/dc034cd0-5433-465c-819a-61c69c80b12c" />

A PCB is in simple words, a circuit board that connects all the components using conductive wires embedded inside of it within layers. In this case, the red lines represent the connections in the top of the board, while the blue wires represent the connections in the back of the board. The pale yellow is simply words/images that are to be printed on the board. The large red images are custom made footprints meant to act as the capacitive touch buttons in the physical PCB.
